# Phase II: final C11 simulator

Compile from the repository root with `gcc -std=c11 -O2 Phase_II/src/Smart_Parking.c -o Smart_Parking.exe` and run `./Smart_Parking.exe` (or `.\Smart_Parking.exe` in PowerShell).

All core algorithms, baselines, CLI, and benchmarks are in one file for easier study and demonstration.
